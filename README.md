# Modern Personal Portfolio & Analytics Admin CMS (MERN Stack)
> **بورتفوليو شخصي احترافي وعصري + نظام لوحة تحكم وإدارة محتوى (Admin Dashboard & Blog CMS) مطابق لتصميم Skymetrics.**

---

## 📊 لوحة التحكم وإدارة الموقع (Admin Dashboard)
تم بناء لوحة تحكم وإدارة كاملة للموقع بمظهر فائق الدقة مطابق لتصميم **Skymetrics** المرفق، ولها مسار خاص مستقل:
👉 **الرابط المباشر:** `http://localhost:5173/admin`

### مميزات لوحة الإدارة (CMS Features):
1. **نظام الإحصائيات البصري (Overview & Analytics):**
   - 8 بطاقات مؤشرات أداء رئيسية (KPI Cards) مطابقة للشكل بالقيم ونسب التغير `+14%`, `-6%`, ...
   - رسم بياني أعمدة (Bar Volume Chart) تفاعلي لحركة الزوار مع Tooltip مخصص ليوم 17 مارس.
   - رسم بياني منحنيات (Spline Curve Chart) لمعدلات التفاعل وقراءة المشاريع.
2. **إدارة ورفع المشاريع (Projects Manager):**
   - إضافة مشروع جديد بالكامل مع رفع الروابط والـ Thumbnail والتصنيفات (Data Analysis, AI, Web Apps, ...).
   - تعديل بيانات أي مشروع وحذف أي مشروع، مع انعكاس التغييرات فوراً في الموقع العام.
3. **نظام التدوين والمقالات (Articles & Blog CMS):**
   - كتابة ونشر مقالات تقنية جديدة حول تحليل البيانات والذكاء الاصطناعي والـ Vibe Coding.
   - تعديل المقالات وتحديد فترات القراءة وصور الغلاف.
   - ظهور المقالات المنشورة فوراً في قسم المقالات بالموقع العام وعلى الرابط الفردي: `/articles/:slug`.
4. **صندوق رسائل التواصل (Messages Inbox):**
   - استعراض جميع الرسائل الواردة من نموذج التواصل في الموقع مع إمكانية الرد بضغطة زر أو حذف الرسائل.
5. **تعديل الملف الشخصي والبيانات (Site & Profile Settings):**
   - تعديل المسمى الوظيفي، النبذة الشخصية، بيانات التواصل، وروابط GitHub و LinkedIn وحفظها بضغطة واحدة.

## 🎨 لوحة الألوان ورموز التصميم (Design Tokens)
- **`--ink: #222936`** (Navy داكن): خلفية الهيرو، شريط التنقل العلوي، الفوتر.
- **`--slate: #374159`** (Dark رمادي-أزرق): بطاقات الهيرو وصورة البروفايل.
- **`--sage: #B9D895`** (أخضر ليموني هادئ): الأزرار الرئيسية وحلقة الصورة والدوائر المميزة.
- **`--mint: #E0F6C4`** (نعناعي فاتح): خلفية قسم الأعمال وصفحة المشاريع.
- **`#F4F5F7` / `#FFFFFF`**: الألوان الفاتحة العصرية المستوحاة من لوحة تحكم Skymetrics لصفحة الإدارة.

---

## 📁 هيكل المسارات (Application Routes)
- `/` : الصفحة الرئيسية (الهيرو، الخدمات، عن المطور، الأعمال، المقالات، التواصل، الفوتر).
- `/projects/:slug` : صفحة تفاصيل دراسة الحالة والمشروع.
- `/articles/:slug` : صفحة قراءة المقال التقني الكامل.
- `/admin` : لوحة التحكم وإدارة المحتوى الشاملة.

---

## 🚀 تشغيل النظام بالكامل (One Command):

```bash
npm run dev
```
- **الموقع العام:** `http://localhost:5173`
- **لوحة التحكم (Admin):** `http://localhost:5173/admin`
- **سيرفر الـ API:** `http://localhost:3000`
