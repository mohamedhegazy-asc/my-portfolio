# Mohamed Hegazy — Professional Portfolio & Analytics Management Platform

> A modern, full-stack personal portfolio and content management platform built to showcase Data Analysis, Artificial Intelligence, and modern software engineering solutions.

---

## 🌟 Overview

This platform serves as a central digital hub to present professional projects, technical case studies, and thought-leadership articles. It is equipped with a custom-built administrative control panel that allows full real-time control over content, live visitor analytics, and direct communication channels.

---

## ✨ Key Highlights

- **Multilingual Experience (العربية / English):** Seamless bidirectional switching with full Right-to-Left (RTL) and Left-to-Right (LTR) typographic flow across all views.
- **Projects & Case Studies Showcase:** Interactive gallery showcasing Data Analysis, AI workflows, business intelligence dashboards, and full-stack applications with live demos and repository links.
- **Publishing & Technical Blog:** Built-in publication system delivering rich technical articles with real-time timestamps, categories, and view counters.
- **Executive Admin Dashboard:** Intuitive management suite providing real-time KPI metrics, visitor volume tracking, content creation, and message inbox management.
- **Real-Time Analytics Engine:** Granular engagement monitoring including unique visits, page views, case study interactions, and curriculum vitae downloads.
- **Cloud Database Persistence:** Centralized data storage ensuring all updates, metrics, and communications are preserved and synchronized.

---

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mohamedhegazy-asc/my-portfolio.git
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development environment:**
   ```bash
   npm run dev
   ```
